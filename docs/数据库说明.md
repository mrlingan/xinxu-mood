# 数据库存储

数据库 `xinxu.db`，Room schema 版本 2。

| 表 | 字段 | 说明 |
|---|---|---|
| entries | id TEXT PRIMARY KEY | UUID，编辑使用同一 ID |
| entries | occurredAt INTEGER | 实际发生时间，UTC epoch 毫秒，有索引 |
| entries | feeling INTEGER | 整体感受 1–5，1 很难受、5 很舒服 |
| entries | emotions TEXT | 例如 `平静:3|焦虑:4`，每种情绪独立记录强度 |
| entries | tags TEXT | `工作|关系`，自定义输入限制分隔符 |
| entries | note / thought / need TEXT | 事件、想法、需要，分别最多 10,000 字符 |
| entries | updatedAt INTEGER | 最近更新时间 |
| entries | media TEXT NOT NULL DEFAULT '[]' | 附件 JSON 数组：id/file/mime/kind/motion，最多 9 个 |
| exercises | id TEXT PRIMARY KEY | UUID |
| exercises | type TEXT | 呼吸练习、情绪整理、短暂停顿 |
| exercises | finishedAt INTEGER | 完成时间，UTC epoch 毫秒 |
| exercises | seconds INTEGER | 练习持续秒数 |
| exercises | before / after INTEGER | 调节目标情绪的练习前后主观强度 1–5 |
| exercises | notes TEXT | 四步整理内容 |

所有业务写操作使用 Room suspend DAO；备份 snapshot 和 replaceAll 都有事务边界。记录按发生时间倒序。设置独立保存在 DataStore preferences 中。

趋势按当前设备时区的自然日聚合，取当天所有记录 feeling 的算术平均数；缺失日期为 null。情绪分布统计记录中该情绪出现的次数，不把强度当作整体感受。场景统计只描述关联，不推断因果。

## 1 → 2 升级

执行 `ALTER TABLE entries ADD COLUMN media TEXT NOT NULL DEFAULT '[]'`，其余字段和练习表保持原有内容。

附件在 `files/memories/` 下，以 UUID 文件名引用。photo 使用原图文件，video 使用视频文件，live 同时引用原图和可播放的视频片段；数据库不保存 BLOB 或外部 URI。系统文件授权结束后仍可离线查看。删除记录的短暂撤销保留文件，超过 24 小时的未引用文件在后续启动清理。备份恢复先创建新文件再提交数据库，失败时撤销新文件。

轻振设置使用新键 `breath_haptics_breeze_v1`，缺省 false；旧键不迁移。`breeze_level` 为 0–2，缺省 0。`quote_index` 单独自增轮换文案，不进入记录备份。
