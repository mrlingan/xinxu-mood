## 1.0.1 呼吸训练震动反馈

- 在吸气/呼气阶段开始时触发一次系统轻触反馈，不随 200 ms 计时刷新重复震动。
- 仅在呼吸训练进行中且页面处于 RESUMED 时触发；其他练习不触发。
- 准备页、训练页均提供开关，选择持久化到 DataStore。
- 不新增权限，遵循系统触感设置。真实振动强度和手感需要实体手机确认。

本次重新执行 `assembleDebug`、6 项 JVM 回归测试、`lintDebug` 均通过。数据库相关 5 项设备测试沿用第一版记录，存储结构未修改。

模拟器已检查震动开关默认开启、关闭后重新进入保留选择、练习中重新开启、切到后台再返回以及结束练习。实际硬件震感未验证。

## 1.0.2 连续渐变振动（2026-10-25）

- 改用连续振幅波形，4 秒线性渐强、6 秒线性渐弱，无停振段；圆形动画使用同一呼吸进度。
- 振幅 24–144，每 50 ms 采样。单次请求覆盖剩余时长，不无限重复；到时自然结束。
- 回到前台从当前呼吸阶段继续。开关关闭、训练结束、页面销毁、锁屏/退到后台主动取消。
- 增加 VIBRATE 普通权限；不支持振幅控制时显示提示、禁用开关，避免退化成恒定振动。
- 新增 4 项波形测试：渐强渐弱、非零振幅与总时长、从中途接续、循环衔接和结束后空波形。共 10 项 JVM 测试通过，assembleDebug 和 lintDebug 通过。
- 模拟器具备 AMPLITUDE_CONTROL，通过系统 vibrator_manager 检查：训练中 running，关闭开关后无活动振动；回到前台 running；后台与结束后均无活动振动。摘要见 test-results/linear-vibration-service.txt。
- 实体手机的实际渐变手感仍待体验；硬件类型无法通过此实现改变。

## 1.0.3 轻柔振动（2026-10-25）

根据用户真机反馈，将渐变振幅从 24–144 降至 8–48，约原指令振幅三分之一，保持连续渐强渐弱与停止机制。10 项 JVM 回归测试、APK 构建和 Lint 均通过。舒适度需在用户手机上体验确认。


## 1.1.0 微风花园（2026-10-26）

### 已完成

- 呼吸连续轻振默认关闭；升级使用新设置键，旧版开启状态不自动继承。三档指令峰值分别为 3、6、10，最低非零振幅 1，每 50 ms 采样，4 秒渐强、6 秒渐弱。
- 触觉用途明确设为 TOUCH，较旧 Android 使用对应的音频属性。关闭、结束、弹窗销毁、暂停或退到后台会取消振动。
- “记录此刻”增加原图、实况、视频，复制到应用私有目录；最多 9 个、单文件 200 MiB。照片可双指缩放，实况长按播放，视频播放/暂停；未识别动态部分时提供短视频配对。
- 16 条原创文案按前台打开轮换；新的偏好索引保存到 DataStore。
- 原生 Sketch 内创建并保存 31 个图标和微风兔插画，均为可编辑矢量，交付 SVG 和 PNG。主界面无 emoji 图标。
- 奶油色/鼠尾草绿主题，导航切页淡入轻移、图标按压回弹、弹窗进出动画。保留标签页滚动状态。
- 备份包含文字和全部媒体，采用分块认证加密，保留旧格式导入；旧数据库通过 1 → 2 迁移保留原内容。

### 实际界面和真机验证

- 独立模拟器实际从系统文件选择器选取实况原图，识别为“实况”、显示本地图像和预览入口；编辑和首页截图在 screenshots/v1.1.0。
- PJZ110 真机以同签名 install -r 从 1.0.3 升至 1.1.0；升级前后原有情绪和练习字段的内容散列一致，schema 从 1 升到 2。备份只保留在本机 .tools 验证目录，未打入交付包。
- 真机确认新开关初始关闭。由用户解锁应用后，短暂启动最低羽毛档；系统报告用途 TOUCH、scaleFactor 1.00，实际振幅 0.003921569–0.011764706（即 1–3/255）。旧版 UNKNOWN 用途曾出现 VERY_HIGH (1.96) 放大。
- 退出练习后系统 CurrentVibration 为 null，最终开关恢复为 OFF。测试未新增或修改真机日记和练习记录。

### 验证边界

- 体感舒适度需用户亲手确认，日志只能验证发送的波形和启停。软件不能强制马达类型、频率或保证不同手机的触感一致。
- 厂商私有实况格式不保证自动识别，需选原图或使用照片加短视频配对；媒体格式可播放性受 Android 系统解码器影响。
- 动画已加入并进行界面检查，未将其称为所有机型上的 iOS 性能或帧率保证。Android 8.0 等低版本尚未做运行验证。
- 仍为调试签名离线版本；系统凭据由用户本人验证，通知准点到达和长期体验仍需继续实用验收。
