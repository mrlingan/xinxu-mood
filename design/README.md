# 心绪 · 微风花园

`心绪-微风花园.sketch` 是在本机 Sketch 中通过原生矢量图层创建、排版并保存的设计源文件。包含导航、5 种整体感受、8 种情绪、练习、图片/实况/视频及辅助图标，共 31 个图标和 1 幅微风兔插画。

`exports/` 为 Sketch 导出的 SVG、2x PNG 与完整画板预览；应用 `drawable-nodpi` 使用这些 PNG。颜色为奶油白、鼠尾草绿、杏桃粉、浅麦黄和低饱和绿灰轮廓。

`create_sketch_design.py` 生成原始 SVG 规格及 Sketch 创建脚本。运行 Python 生成脚本可重新生成 Sketch 创建脚本，然后在 Sketch 的“插件 → 运行脚本”中执行。已有源文件可直接在 Sketch 里继续编辑，无需执行脚本。
